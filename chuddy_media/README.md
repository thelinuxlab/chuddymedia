# Chuddy Media
Setup: `pip install -r requirements.txt` then `python manage.py makemigrations studio && python manage.py migrate && python manage.py seed && python manage.py createsuperuser && python manage.py runserver`
Add work, companies and vendors at /admin/. Set URL_FACEBOOK, URL_X, URL_TIKTOK, URL_YOUTUBE env vars to show those social links.
